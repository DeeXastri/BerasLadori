# 🌾 PROJECT HEADQUARTERS: DISTRIBUTOR RESMI BERAS LADORI & DIHOREIN
### *Penguasaan Pasar Teritorial Mesin Pencari & Distribusi Grosir Wilayah Magelang & Temanggung*

Selamat datang di direktori pusat operasional proyek digitalisasi dan dominasi pasar distributor resmi beras untuk wilayah Kota Magelang, Kabupaten Magelang, dan Kabupaten Temanggung. 

Proyek ini mengeksekusi strategi **Dual-Brand Portfolio**:
1. **Beras Premium Ladori (Top Tier Flagship):** Super pulen, aroma wangi alami, kemasan 5kg, 10kg, 25kg, 50kg. Target: Toko sembako modern, katering pernikahan, HOREKA Borobudur, dan Satuan Pelayanan Pemenuhan Gizi (SPPG MBG).
2. **Beras DiHorein (Value Champion):** Pulen mekar, tahan basi >20 jam, kemasan 25kg & 50kg, satu level harga di bawah Ladori. Target: Dapur umum pondok pesantren, asrama santri, yayasan yatim piatu, katering hemat, dan warteg.
